# 이도훈

해양컴퓨터공학을 전공하고, 클라우드·인프라 직무를 준비하고 있습니다.
팀 프로젝트에서는 백엔드 개발과 배포를 맡았습니다. FastAPI와 PostgreSQL로 서비스를 만들고, AWS EKS와 GCP에 배포했습니다.
개인 서버에서도 Docker로 서비스를 올리고 모니터링과 백업을 관리해 왔습니다.

## 프로젝트

### [AWS EKS BookShelf](https://github.com/owlooo/aws-eks-cicd-book-service)
도서 관리 서비스의 Docker 이미지와 EKS 배포 설정을 작성했습니다.
dev/prod 환경을 분리하고, DB 연결 한도를 고려해 HPA 확장 상한을 조정했습니다.

### [AI’s EYE](https://github.com/owlooo/ai-s-eye)
5인 팀에서 팀장을 맡아 공통 API·DB와 운영 분석 기능을 만들고, 팀원들의 기능을 연결했습니다.
개발용 미니PC와 시연용 GCP의 자동 배포를 구성했습니다.

KT AIVLE Big Project Collaboration 수상 · 2026.09.03

### [ManuAI-talk](https://github.com/owlooo/manuai-talk)
제품 매뉴얼을 바탕으로 질문에 답하는 서비스입니다. 프런트엔드를 맡아 제품별 채팅과 음성 입출력을 연결하고, 제품 관리·QR·AR 화면을 구현·개선했습니다.

광주인공지능사관학교 우수상 · 2025.12.11

## 프로젝트에서 사용한 기술

- **배포:** Docker · Kubernetes/EKS · ECR · CodeBuild · GCP Compute Engine · GitHub Actions
- **개발:** Python · FastAPI · PostgreSQL · React/Next.js · TypeScript

[CStudy](https://github.com/aischool-cstudy/aiplus-cstudy)에서는 학습·실습 화면과 AI 실행 지표를 만들고, DB 저장 오류를 수정했습니다.
