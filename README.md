# 이도훈

안녕하세요, 이도훈입니다. 해양컴퓨터공학을 전공했고, 클라우드·인프라 직무를 준비하고 있습니다.

팀 프로젝트에서 백엔드 개발과 서비스 통합, 배포 환경 구성을 맡았습니다.
AI 매장 운영 서비스는 GCP에, 도서 관리 서비스는 AWS EKS에 배포했습니다.

## 대표 프로젝트

### [AI’s EYE · 매장 운영 지원 서비스](https://github.com/owlooo/ai-s-eye)
영상 분석 결과와 주문 데이터를 모아 매장 상황을 확인하고, 직원 수에 따른 운영안을 비교하는 서비스입니다.
5인 팀의 팀장으로 공통 API·DB와 운영 분석 기능을 개발했습니다. 팀원의 기능을 연결하고, 개발용 미니PC와 시연용 GCP의 자동 배포를 구성했습니다.

KT AIVLE Big Project Collaboration 수상 · 2026.09.03

### [BookShelf · AWS EKS 배포](https://github.com/owlooo/aws-eks-cicd-book-service)
도서 관리 서비스의 Docker 이미지와 EKS 배포 설정을 작성하고 개발·운영 환경을 분리했습니다.
Pod가 늘어날 때 DB 연결도 함께 늘어나는 점을 고려해 HPA 상한을 조정하고, 부하에 따른 Pod 확장을 확인했습니다.

### [ManuAI-talk · 제품 매뉴얼 AI 상담](https://github.com/owlooo/manuai-talk)
6인 팀에서 프런트엔드를 주로 맡았습니다. 제품별 채팅과 음성 입출력을 연결하고, 제품 관리·QR·AR 화면을 구현·개선했습니다.

광주인공지능사관학교 우수상 · 2025.12.11

## 개인 서버
Docker 기반 서비스와 모니터링·백업 환경을 구성해 왔습니다.
서비스에 접속되지 않을 때 앱·컨테이너·프록시·DNS를 나눠 확인하고, 복구 절차를 기록했습니다.

## 프로젝트에서 사용한 기술
- **배포:** Docker · Kubernetes/EKS · ECR · CodeBuild · GCP Compute Engine · GitHub Actions
- **개발:** Python · FastAPI · PostgreSQL · React/Next.js · TypeScript
