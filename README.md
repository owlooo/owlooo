# 이도훈

AI 서비스를 개발하고 AWS·GCP 배포 환경을 구성해 온 이도훈입니다.
서비스 구현부터 배포·모니터링까지 연결하는 클라우드 엔지니어를 목표로 합니다.

## 대표 프로젝트

| 프로젝트 | 내가 맡은 일 | 결과 |
|---|---|---|
| [AWS EKS BookShelf](https://github.com/owlooo/aws-eks-cicd-book-service) | Docker·ECR·EKS 배포, CI/CD, dev/prod 분리, HPA | 부하 테스트에서 Pod 2→3 확장 확인 |
| [AI’s EYE](https://github.com/owlooo/ai-s-eye) | 5인 팀장, API·DB, GCP 자동 배포, AI 서비스 통합 | KT AIVLE Big Project Collaboration · 2026.09.03 |
| [ManuAI-talk](https://github.com/owlooo/manuai-talk) | 프런트엔드 주담당, 채팅·음성·제품/QR/AR 연동 | 광주인공지능사관학교 우수상 · 2025.12.11 |

각 저장소에 개인 역할, 문제 해결 사례, 코드·PR 근거를 정리했습니다.
